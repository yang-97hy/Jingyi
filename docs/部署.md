# 部署

## 依赖

- Node.js 20+（脚本用了 node:sqlite 的版本需要 22+，可选）
- 没有任何第三方 npm 依赖（只有桥接本身需要）

## 路径清单（scripts 里是绝对路径，改这些）

| 脚本 | 要改的常量 | 含义 |
|---|---|---|
| mem-health.mjs | LIB / L1 / L0 / CHEM | 记忆库根、索引目录、原话目录、激素文件 |
| make-exam.mjs | LIB / L0 | 同上 |
| exam-score.mjs | 题库目录 | |
| daily-maint.mjs | LIB / LOGDIR / NODE | 加日志目录、node 路径 |
| archive-full.mjs | WS / ROOT | 会话存储目录、归档根 |
| recall-emotion.mjs | LIB / CHEM | |
| hormones.mjs | F | 激素状态文件 |
| tone-profile.mjs | LIB / L0 | |

## 记忆库目录模板

见 `templates/`。直接复制到自己喜欢的位置：

```
我的记忆库/
  L0/            YYYY-MM-DD.jsonl
  L1/            YYYY-MM-DD.index.jsonl
  每日/          YYYY-MM-DD.md
  考试/          题库-*.jsonl / 待标-*.md / 成绩单-*.md
  坑/            坑.jsonl
  语域/          <对象>.md
  归档/<对象>/    NN_日期_会话.md + 索引.md
```

## 桥接要提供什么

见 `docs/接口.md`。最小集：写 L0、给候选、写标注、写每日记忆、读激素、写坑。

## 定时

```powershell
schtasks /Create /TN "MemoryMaint" /TR "node D:\...\daily-maint.mjs" /SC DAILY /ST 23:00 /F
```
