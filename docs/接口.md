# 桥接需要提供的 HTTP 接口

所有接口用 POST + JSON，鉴权自定（示例用 header token）。

## 1. 写 L0

```
POST /api/l0/append
{ "key":"private:xxx", "from":"him|me", "text":"…" }
→ { ok:true, seq:147 }
```

## 2. 取当天候选

```
POST /api/l1/candidates
{ "date":"2026-11-05" }
→ { ok:true, cands:[{ s:147, t:"…", who:"him", score:4 }] }
```

## 3. 写标注（带三条硬校验）

```
POST /api/l1/mark
{ "date":"2026-11-05", "s":147, "imp":2, "quote":"原话片段", "why":"为什么重要", "about":["…"] }
→ { ok:true }
```

## 4. 每日记忆

```
POST /api/memory/archive
{ "items":["[事实] …","[承诺] …","[情绪] …"] }
```

## 5. 情绪

```
GET  /api/chem            → 当前三值
POST /api/chem/touch      { "id":"cortisol", "delta":10 }
```

## 6. 坑

```
POST /api/memory/pitfall
{ "scene":"…", "cause":"…", "lesson":"…" }
```

## 7. 情绪加权检索

```
POST /api/memory/recall-ranked
{ "query":"关键词（可空）", "limit":10 }
→ { ok:true, rows:[{ score:0.58, day:"2026-11-04", quote:"…", parts:{hit,imp,fresh,sal} }] }
```

## 8. 自检

```
GET /api/self/check → 覆盖率、今日标注数、剩余名额、坑数
```
