# 接入钩子（把你的框架接上鲸忆）

> 不管你的框架是 DSH、Claude Code、LangChain 还是自己写的，
> **只要挂上三个钩子 + 两个时机，整套机制就跑起来了。**

## 三个必挂的钩子

### 钩子 1：收到消息 → 写 L0

**位置**：消息进入你的系统、准备交给模型之前。

```js
// 每条消息一条记录，只追加，永不修改
appendFileSync(`${L0}/YYYY-MM-DD.jsonl`, JSON.stringify({
  time: new Date().toISOString(),
  key: 'private:100000001',     // 谁的会话
  from: 'him' | 'me',           // 对方 / 自己
  kind: 'message',
  text: '原文，一个字都不改',
  seq: ++你的自增序号,
}) + '\n');
```

**红线**：`text` 必须是原话。**任何"顺手整理一下"都是错的。**

### 钩子 2：取候选 → 给模型看

**位置**：注入提示词的时候（或模型主动要）。

```js
// 从当天 L0 里挑"可能值得记"的，按机械规则打分，不要用模型判断
const cands = 读当天L0()
  .filter(r => r.from === 'him')
  .map(r => ({ s: r.seq, t: r.text, score: 机械打分(r.text) }))
  .sort((a, b) => b.score - a.score)
  .slice(0, 20);
```

**机械打分参考**：带数字 +2、带"喜欢/答应/决定" +3、带时间词 +2、长度 10~70 +1。

### 钩子 3：写标注 → 带三条硬校验

**位置**：模型调用"记这条"的时候。

```js
if (!当天L0里存在 seq) 拒绝;                 // 防凭空标
if (!原话.includes(quote)) 拒绝;             // 防改写
if (imp >= 2 && !why) 拒绝;                  // 防"标了不知道为什么"
写进 L1/YYYY-MM-DD.index.jsonl
```

**这三条是整个系统的灵魂。** 没有它们，模型会自己编记忆。

## 两个必挂的时机

### 时机 A：轮换前 → 先落盘

```bash
node scripts/pre-rotate.mjs <会话id>
# 退出码 0 = 可以换
# 退出码 2 = 记忆或归档还没落盘，先别换（让上层压缩也行，但别丢记）
```

**它检查三样**：今天的每日记忆有没有更新、这轮会话有没有归档、交接是不是新鲜。

### 时机 B：上下文到 85% → 提醒写记忆

```js
if (已用 / 上限 > 0.85) {
  告诉模型：'要换会话了，先把今天的记忆和交接写下来（记住什么都写）';
  等它写完 → 跑 pre-rotate → 换
}
```

**不要等 100%**，那时候它的判断已经开始糊了。

## 常驻守护（可选但强烈建议）

```bash
node scripts/supervisor.mjs
```

它每 30 秒做一次巡检：

```
① 网关端口（配置了才查）掉了 → 按 startCmd 拉起
② 每天 23:00 → daily-maint（健康报告 + 待标清单）
③ 每 15 分钟 → archive-incremental（把新会话存进归档）
```

**配置写在 `config.local.json`**：

```json
{
  "gateway": {
    "startCmd": "你的网关启动命令",
    "workdir": "网关工作目录",
    "healthPorts": [3000, 3001]
  }
}
```

## 开机自启

```powershell
schtasks /Create /TN "鲸忆-守护" /TR "node D:\path\to\scripts\supervisor.mjs" /SC ONLOGON /F
```

## 自检清单

```
[ ] L0 有没有按天落盘、字段齐不齐
[ ] 标注有没有三条校验（随便标一条假 seq 试试，应该被拒）
[ ] 注入有没有封顶（每块都要有上限）
[ ] 轮换前有没有跑 pre-rotate
[ ] 归档里能不能看到"他说的"和"她想的"（只有她的话说明取错了）
[ ] mem-health 覆盖率是不是在涨
```
